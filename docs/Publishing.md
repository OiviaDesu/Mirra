# Publishing

## License and notices

Mirra's original source and artwork use the [MIT License](../LICENSE). Retain
the copyright and permission notice when redistributing covered copies.
Bundled and external components keep their own terms; see [NOTICE.md](../NOTICE.md).

The project license does not grant rights to Apple's application or system
frameworks. Distributable packages contain Mirra's code and the documented
runtime components rather than Apple binaries or private device material.

## Platform and repository terms

Hackintosh use is outside Apple's supported host configuration. Review the
applicable [Apple software terms](https://www.apple.com/legal/sla/) and
[iCloud terms](https://www.apple.com/legal/internet-services/icloud/en/terms.html)
for the intended use.

For repository publication, review GitHub's
[Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies)
and [DMCA policy](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy).
Successful operation does not establish permission to distribute third-party code.

See [Release guide](Release.md) for artifact preparation and publication steps.
